2. **سؤال التعريف:** هل «أمسية معرفية» و«لقاء مفتوح» و«فعالية حوارية» تُعد كلها `event`؟ البيانات تدعم ذلك ولا تفرضه.
3. **التعميم:** القاعدة مكتوبة لقوالب هذه الألف. إعلان بقالب جديد يعطي `unknown` عمدًا (وليس تخمينًا)، ولا يتحقق ذلك إلا بإضافة العبارة والموضع بمثال حقيقي.
4. النوع هنا **على مستوى المصدر**. في كل الأزواج المئة يتفق المصدران، فالنوع على مستوى الفرصة آمن، لكن قاعدة اختيار النوع عند اختلاف مصدرين ستلزم إن ظهر ذلك.
