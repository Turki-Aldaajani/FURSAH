## 4. ما ينفّذه النظام اليوم

**المسار:** الواجهة `POST /api/v1/discover` ← `routes.py` ← `workflow.discover` ← (تفسير الطلب، بالنموذج إن وُجد ثم القواعد) ← `repository.search` ← استجابة `DiscoveryResponse`. وللتفاصيل: `GET /api/v1/opportunities/{id}` ← `repository.get_details`. عقد الـ API كما في `schemas.py` بلا أي تغيير.

- **`repository.py`:**
  - يحمّل `data/prepared/source_preparation.json` مرة واحدة.
  - يجمّع المصادر في فرص بمفتاح (الرابط + العنوان + الناشر): **900 فرصة** (100 زوجًا و800 منفردة). المفتاح مؤقت ومتحقَّق على هذه البيانات.
  - المعرّف `opp-<12 خانة>` مشتق من المفتاح؛ ويقبل `get_details` أيضًا معرّف أي مصدر.
  - يدمج الحقائق: اتفاق ← قيمة؛ تحديث صريح ← يغلب في حقله؛ تعارض ← `null` مع `data_warnings`.
  - يحسب حالة التقديم عند وقت الطلب (لا وقت التحضير) بسياسة `review_deadlines` (هامش يوم حول تاريخ الرياض).
  - يستبعد الملغى والمغلق والمنتهي. الرسوم المجهولة لا تُعد مجانية.
  - الأهلية دائمًا `uncertain`، والشروط الإلزامية تظهر ملاحظات.
- **`workflow.py`:**
  - يفسّر النوع والمدينة وطريقة التقديم والميزانية والموضوع.
  - يفهم «أو» بين مدينة وعن بُعد كبديلين.
  - يربط بايثون وPython وإكسل وExcel وSQL وPower BI.
  - يستبعد كلمات القوالب والمستوى من أدلة الموضوع.
  - يرتّب بالملف الشخصي (مدينة، مهارة، اهتمام) دون أن يحذف.
  - يطبّق `needs_info` عند تعارض المدينة مع التفضيل المحفوظ.
- **`agent.py`:**
  - عميل `httpx` بروتوكول OpenAI-compatible (لا SDK ولا إطار).
  - يرسل نص الطلب وقائمة المدن فقط.
  - يقبل خطة النموذج بشروط: اقتباس حرفي من الطلب لكل مرشح، وقيم من قوائم مغلقة، وألا تحذف الخطة ما وجدته القواعد، و«أو» لا تُقبل إلا إن وردت الكلمة.
  - عند أي فشل يرجع البحث للقواعد الأساسية ويكتب ذلك في الفلاتر.
- **`data/opportunity_type_rules.py`:** `classify_type(content, source_name)` بـ11 موضعًا قالبيًا و18 عبارة، لا مطابقة لكلمات مفردة.

## 12. حادثة `FURSAH_NETWORK_ERROR` أثناء البحث (21 أكتوبر 2026، مُصلحة)

- **العَرَض:** بحث يعمل ثم يظهر «تعذر الاتصال بالخادم» والخادم حيّ.

- **ما استُبعد بالأدلة:** توقف العملية (الخادم يعمل دون انقطاع منذ 20:56:41)، انهيار python (لا شيء في سجل التطبيقات)، نقص الذاكرة (لا أحداث استنزاف)، CORS للطلبات العادية (سليم)، المنفذ والعنوان (سليمان).
- **الإصلاح (ملفان):** `backend/app/agent.py`: (1) محتوى غير نصي أو فارغ يصير `InvalidModelOutputError` فيرجع البحث للقواعد الأساسية بدل الانهيار؛ (2) إرسال `reasoning: {"enabled": false}` لـOpenRouter فقط (OpenAI نفسه يرفض معاملات غير معروفة). و`backend/tests/test_model_integration.py`: +2 اختبار.
- **التحقق:** 41 اختبارًا ناجحًا. والاختبار الجديد **يفشل على الكود القديم** بنفس الاستثناء. وبعد الإصلاح: 22 طلبًا متنوعًا + 8 تكرارات للطلبين الفاشلين بالنموذج الحقيقي ← **0 خطأ، 0 استجابة 500، 0 تتبّع أخطاء**، والخادم حيّ بعد 32 طلبًا. وتجربة مباشرة بتعطيل التفكير: من 500 رمز تفكير وفشل إلى 0 رمز، ومن 5–7 ثوان إلى 2–3 ثوان، وتكلفة أقل.
